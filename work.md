Before modifying anything, create a step-by-step improvement roadmap.

1. Critical bug fixes
2. Architecture improvements

5. Frontend improvements

7. Performance optimization

Do not blindly rewrite the project.

1. Explain what you are changing
2. Explain why
3. Modify the necessary files
4. Keep existing features working
5. Check for errors
6. Check for broken imports/dependencies
7. Check integration between components
8. Verify that the change does not break another feature
